# The-Gym-Company-Prototype

Created from the supplied WEDE5020 Website Proposal.

Pages:
- index.html — Home
- about.html — About Us
- contact.html — Contact Us
- clubs.html — Find a Gym / Club Finder
- membership.html — Membership / 3-step sign-up concept
- classes.html — Classes / booking concept
- dashboard.html — Member Dashboard concept
- shop.html — E-commerce concept
- styles.css — shared responsive styling


- The proposal calls for a 20+ page-template UI, but it does not specify the content of every individual template. This prototype therefore implements the core pages and major functional areas explicitly described in the proposal.
- Membership prices are placeholders because the supplied proposal does not provide prices.
- Maps and geolocation, real occupancy, payments, member data, class APIs, e-commerce checkout, email marketing, analytics, POPIA consent storage and authentication are front-end placeholders until the specified integrations/backend are connected.
- Images were took from Unsplash URLs in the HTML so the prototype has visual content immediately when opened with internet access.
- Member stories have been updated in the html code.
- About-Us.html now has an accordion for the club timeline.
- Join-Now.html now has a progress bar for registering new  members.
- Services.html has new tabbed panels for facilities, classes and personal training.
- Contact-Us has a new interactive map as well as a leaflet.
- Mild changes to the CSS code have been added as well to improve user experience.
